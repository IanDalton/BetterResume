You are extracting structured resume data from the raw text of a LinkedIn profile PDF export ("Save to PDF"). The text may be in any language, and its section headers (Contact, Summary, Experience, Education, Skills, Languages, etc.) may be localized rather than in English.

Extract exactly the following, and nothing more:

- profile: full_name; headline (the short tagline shown under the name); summary (the "About" section body, verbatim); location (city/region shown near the name); email and phone ONLY if explicitly present in a Contact section (leave null otherwise -- do not guess); links: any URLs found (LinkedIn profile URL, personal site, GitHub, portfolio, etc.), each with a best-guess "kind" (one of: portfolio, github, linkedin, twitter, blog, other) and the "url" itself.

- experience: one entry per work-experience item, with type="job", role (job title), company, location if shown, and start_date/end_date. Normalize dates to DD/MM/YYYY using 01 as the day (LinkedIn only ever gives month + year), or end_date="present" for roles marked as ongoing (in any language -- e.g. "Present", "Actualidad", "En cours"). description should be the bullet or summary text under that role, copied verbatim -- do not paraphrase, summarize, or invent content that isn't there.

- education: one entry per education item, with type="education", role=degree/field of study, company=institution name, location if shown, start_date/end_date normalized the same way as experience, and description containing any additional details listed (honors, activities, coursework) or an empty string if none are given.

- skills: a flat list of skill-name strings, taken directly from the Skills section if present.

- languages: name + proficiency pairs, taken directly from the Languages section if present, in whatever language/format LinkedIn shows them.

- warnings: a short plain-language note for any entry where a field could not be parsed with confidence (e.g. an ambiguous or malformed date). Leave this empty if nothing was ambiguous.

Rules:
- Never invent data that is not present in the source text. If a section is entirely absent, return an empty list for it -- do not guess or fabricate placeholder entries.
- Do not translate extracted values into another language -- keep names, roles, and descriptions exactly as they appear in the source.
- Ignore page-footer boilerplate (page numbers, the profile's own LinkedIn URL) if it appears mixed into the body text.
